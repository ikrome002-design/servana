## Servana translation

- Use the existing Servana shell and token system only: primary orange, sun, green, brown, teal,
  sand, cream, adaptive charcoal/gray; Inter for UI and Manrope for page titles.
- Apply asymmetric hierarchy where it improves decisions: Dashboard workforce pulse + action rail;
  Staff Detail identity + readiness; Compensation Detail declared terms + lifecycle/history.
- Prefer compact status badges, branch-context strips, task-led empty states and progressive
  disclosure. No invented totals, charts, earnings, payment success, notification or export state.
- Preserve light mode as the first render, full tokenized dark mode, 44px targets, visible focus,
  fixed-footer reserve, desktop sidebar, tablet rail and focus-trapped mobile drawer.
- This is reference analysis, not permission to copy another product's brand, layout verbatim,
  text, data model, interaction, icons or unsupported capability.
