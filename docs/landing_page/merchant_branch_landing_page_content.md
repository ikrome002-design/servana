## 13. FAQ Section

## Can a branch create its own account directly?

No. A branch is managed under a merchant account. The Merchant Administrator starts by creating the business account, then branches are added and managed inside that merchant workspace.

## What can a branch manage in Servana?

A branch can manage its profile, operating hours, service availability, personnel assignments, queue, appointments, branch revenue, invoices, receipts, payment records, and branch-level audit logs. 

## Does Servana process payments?

No. Servana records offline payments and payment validation details, but client-to-merchant payments happen off-platform through methods such as cash, M-Pesa, bank transfer, card terminal, voucher, split payment, or other merchant-defined methods. 

## Can users only see the branch they are assigned to?

Branch access is controlled by permissions and branch assignment. Servana is designed so users only access the merchant and branch data they are authorized to use. 

## Is Servana only for salons?

No. Servana is built for service-based SMEs such as salons, barbershops, spas, massage parlours, grooming studios, beauty parlours, and similar businesses.

## What happens when I click GET STARTED?

You are directed to login and create account functionality. From there, the Merchant Administrator can register the business account and begin setting up the merchant workspace.

## 14. Security / Compliance Section

# Your branch records deserve serious protection.

Servana is designed for secure merchant and branch operations. Each merchant operates as an isolated tenant, and merchant data must not be accessible, inferable, editable, exportable, or enumerable by another merchant. 

Branch access is controlled through user status, role status, merchant assignment, branch assignment where applicable, and secure Magic Link login rules. 

**In simple terms:**
Your branch gets the visibility it needs, while access stays controlled.
